PROJECT OVERVIEW

Track everyday routines without a backend.

StreakTracker is a newly generated, AI-assisted Android sample exploring reactive UI, local persistence, independent habit calendars and optional reminders.

KotlinJetpack ComposeMVVMStateFlowDataStoreWorkManager

Architecture

Compose UI → ViewModel → Repository → Preferences DataStore. The Android source separates reactive state, persistence and reminder scheduling.

Engineering focus

Independent habit states, month navigation, current-streak calculation, and lifecycle-aware state collection. The reminder is optional and timing is approximate.

Project status

This is a new demo, not a previously published app. Native build and runtime behavior still require verification. The interactive preview is a browser prototype, not an Android screenshot. No production usage metrics are claimed.
